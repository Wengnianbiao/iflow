# interface-agent 模块化架构说明

## 📦 模块结构

```
interface-agent/
├── agent-common/                    # 共享基础设施
│   ├── exception/                   # 异常定义
│   ├── utils/                       # 工具类
│   ├── common/                      # 公共常量、枚举
│   └── annotation/                  # 自定义注解
│
├── agent-workflow/                  # 工作流模块 ⭐
│   ├── model/                       # 实体类、DTO、枚举
│   ├── service/                     # 工作流服务
│   ├── mapper/                      # MyBatis Mapper
│   ├── controller/                  # 工作流管理API
│   └── converter/                   # 对象转换器
│
├── agent-invocation/                # 远程调用模块 ⭐
│   ├── client/                      # 客户端实现(HTTP、WebService、Database等)
│   ├── service/                     # 调用服务
│   ├── parameter/                   # 参数处理
│   └── spi/                         # SPI扩展接口
│
├── agent-schedule/                  # 调度模块 ⭐
│   ├── service/                     # 调度服务
│   │   ├── WorkFlowEngineScheduler  # 工作流引擎调度器
│   │   ├── FlowNodeDispatcher       # 节点分发器
│   │   └── ContentParser            # 内容解析器
│   ├── processor/                   # 处理器
│   └── executor/                    # 执行器
│
├── agent-api/                       # 开放API模块 ⭐
│   ├── model/                       # API模型
│   ├── service/                     # API服务
│   ├── controller/                  # API控制器
│   └── parser/                      # 解析器
│
├── agent-log/                       # 日志模块
│   ├── model/                       # 日志实体
│   ├── service/                     # 日志服务
│   ├── mapper/                      # 日志Mapper
│   └── controller/                  # 日志查询API
│
├── agent-mock/                      # Mock模块
│   ├── model/                       # Mock配置实体
│   ├── service/                     # Mock服务
│   ├── mapper/                      # Mock Mapper
│   └── controller/                  # Mock管理API
│
├── agent-spring-boot-starter/       # Spring Boot启动器 🚀
│   ├── config/                      # 自动配置类
│   ├── aspect/                      # AOP切面
│   ├── log/context/                 # 日志上下文
│   ├── starter/                     # 自动装配
│   ├── resources/                   # 配置文件
│   └── InterfaceAgent.java          # 应用启动类
│
└── agent-web/                       # Web应用模块 🌐
    └── resources/                   # 静态资源、配置文件

```

## 🔗 模块依赖关系

```
agent-common (基础层)
    ↑
    ├── agent-workflow
    ├── agent-invocation
    │       ↑
    │       └── agent-schedule
    │       └── agent-mock
    ├── agent-api
    └── agent-log
            ↑
            └── agent-spring-boot-starter
                    ↑
                    └── agent-web (应用层)
```

## 🎯 核心特性

### 1. 模块化分层
- **基础层**: agent-common提供共享组件
- **核心层**: workflow、invocation、schedule实现核心业务
- **功能层**: api、log、mock提供扩展功能
- **启动层**: spring-boot-starter整合所有模块
- **应用层**: agent-web作为可执行入口

### 2. SPI扩展机制
- 使用Dubbo SPI实现可插拔的远程调用客户端
- 支持HTTP、WebService、JDBC等多种协议
- 可通过配置或代码动态扩展

### 3. 配置化设计
- 工作流节点配置存储在数据库
- 支持动态修改流程无需重启
- 参数映射支持SpEL表达式

## 🚀 构建与运行

### 编译打包
```bash
mvn clean package -Dmaven.test.skip=true
```

### 运行应用
```bash
java -jar agent-web/target/interface-agent.jar
```

## 📋 命名规范优化

### 已优化项
✅ agent-starter → **agent-spring-boot-starter** (符合Spring Boot规范)
✅ 删除冗余的 agent-service、agent-model 模块
✅ agent-web打包名称改为 **interface-agent.jar**
✅ 主启动类位于 agent-spring-boot-starter

### 清晰的职责划分
- **agent-spring-boot-starter**: 自动配置、切面、启动入口
- **agent-web**: 仅包含静态资源和应用配置
- **各功能模块**: 独立负责各自的业务领域

## 🔧 技术栈

- **Spring Boot**: 2.3.2.RELEASE
- **MyBatis**: 数据持久化
- **Dubbo SPI**: 扩展点加载
- **Quartz**: 定时调度
- **SpEL**: 表达式引擎
- **Swagger**: API文档
