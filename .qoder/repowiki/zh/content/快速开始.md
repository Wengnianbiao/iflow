## 简介

本快速开始指南旨在为新用户提供清晰的入门路径，帮助您在最短时间内成功运行或集成 Interface Agent 工作流引擎。系统支持两种使用模式：作为独立应用运行和作为 Spring Boot Starter 集成到现有项目中。无论您选择哪种方式，本指南都将提供详细的步骤说明。

## 先决条件与环境要求

在开始之前，请确保您的开发环境满足以下要求：

- **Java 8 或更高版本**：系统基于 Spring Boot 2.3.2.RELEASE 构建，需要 Java 8+ 运行环境
- **Maven 3.5 或更高版本**：用于项目构建和依赖管理
- **Git**：用于克隆代码仓库
- **数据库支持**：支持以下任意一种数据库
  - MySQL 5.7+
  - SQL Server 2012+
  - Oracle 12c+
  - OpenGauss 3.0+
- **网络访问权限**：确保可以访问所需的数据库服务器和外部服务（如 HTTP、WebService）

## 使用模式一：独立应用运行

此模式适用于希望独立部署和使用 Interface Agent 的用户。通过运行 `agent-web` 模块，您可以获得一个完整的 Web 应用，包含前端配置界面和后端服务。

### 克隆仓库

首先，从代码仓库克隆项目到本地：

```bash
git clone <repository-url>
cd interface-agent-dev
```

**Section sources**
- [README.md](file://README.md#L192-L194)

### 编译安装

使用 Maven 编译并安装所有模块到本地仓库，跳过测试以加快构建速度：

```bash
mvn clean install -DskipTests
```

此命令将编译所有子模块（如 agent-common、agent-workflow、agent-spring-boot-starter 等）并安装到本地 Maven 仓库，确保所有依赖项都已准备就绪。

### 初始化数据库

根据您使用的数据库类型，执行相应的初始化 SQL 脚本。这些脚本位于 `doc/` 目录下：

```bash
# 对于 MySQL
mysql -u root -p < doc/init_mysql.sql

# 对于 SQL Server
sqlcmd -S server -U username -P password -i doc/init_sqlserver.sql

# 对于 OpenGauss
gsql -d postgres -U username -W password -f doc/init_gauss.sql
```

这些脚本将创建 `interface_agent` 数据库（如果不存在），并创建以下核心表：
- `interface_workflow`：工作流定义表
- `interface_workflow_node`：工作流节点表
- `node_param_config`：节点参数映射配置表
- `interface_invoke_log`：调用日志表
- `mock_config`：Mock 配置表
- `node_extension_config`：SPI 扩展配置表

### 配置数据源

编辑 `agent-web/src/main/resources/application.yml` 文件，配置 `agent` 和 `hems` 两个数据源。`agent` 数据源是必需的，用于存储工作流元数据；`hems` 是可选的业务数据源。

示例配置（MySQL）：

```yaml
spring:
  profiles:
    active: dev-mysql
  datasource:
    # agent元数据数据源（必须）
    agent:
      type: com.alibaba.druid.pool.DruidDataSource
      driver-class-name: com.mysql.cj.jdbc.Driver
      url: jdbc:mysql://localhost:3306/interface_agent
      username: root
      password: your_password
    # 业务数据源（可选）
    hems:
      type: com.alibaba.druid.pool.DruidDataSource
      driver-class-name: com.mysql.cj.jdbc.Driver
      url: jdbc:mysql://localhost:3306/your_business_db
      username: root
      password: your_password

pagehelper:
  helper-dialect: mysql
```

您也可以使用预定义的配置文件，如 `application-dev-mysql.yml`、`application-dev-sqlserver.yml` 等，并通过 `spring.profiles.active` 指定激活的配置。

### 启动应用

编译完成后，启动 `agent-web` 模块：

```bash
java -jar agent-web/target/interface-agent.jar
```

或者在 IDE 中运行 `InterfaceAgentApplication` 类的 `main` 方法。

启动成功后，您将在日志中看到类似信息：
```
Interface Agent Auto Configuration initialized!
工作流引擎已启动，可以使用前端配置页面和API调用
```

默认情况下，应用将在端口 8099 上运行（可在配置文件中修改）。

## 使用模式二：作为Spring Boot Starter集成

此模式适用于希望将工作流引擎集成到现有 Spring Boot 项目中的用户。通过引入 `agent-spring-boot-starter`，您可以将强大的工作流功能嵌入到您的应用中。

### 添加依赖

在您的 Spring Boot 项目的 `pom.xml` 中添加 `agent-spring-boot-starter` 依赖：

```xml
<dependency>
    <groupId>com.helianhealth</groupId>
    <artifactId>agent-spring-boot-starter</artifactId>
    <version>1.0.1</version>
</dependency>
```

该 Starter 会自动引入必要的模块，包括 `agent-config`（CORS、异常处理等）和 `agent-api`（核心 API 接口）。

### 启用与配置

`agent-spring-boot-starter` 使用 Spring Boot 的自动配置机制。只要依赖在类路径中，`InterfaceAgentAutoConfiguration` 就会自动生效。

您可以通过以下配置控制其行为：

```yaml
interface-agent:
  enabled: true  # 默认为 true，可显式禁用
```

自动配置类 `InterfaceAgentAutoConfiguration` 使用了 `@ConditionalOnProperty` 注解，确保只有在 `interface-agent.enabled` 为 `true`（或未配置）时才会加载。

## 配置示例

以下是一个完整的 MySQL 数据库配置示例，适用于大多数开发环境：

```yaml
server:
  port: 8080

spring:
  application:
    name: my-application
  profiles:
    active: dev
  datasource:
    agent:
      type: com.alibaba.druid.pool.DruidDataSource
      driver-class-name: com.mysql.cj.jdbc.Driver
      url: jdbc:mysql://localhost:3306/interface_agent?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
      username: root
      password: root
      initial-size: 5
      max-active: 50
      min-idle: 5
      max-wait: 30000
      validation-query: SELECT 1
      test-while-idle: true

      type: com.alibaba.druid.pool.DruidDataSource

      password: root
      initial-size: 5
      max-active: 50
      min-idle: 5
      max-wait: 30000
      validation-query: SELECT 1
```

## 常见问题与故障排除

1. **启动失败：数据库连接错误**
   - 检查 `application.yml` 中的数据库 URL、用户名和密码是否正确
   - 确保数据库服务正在运行且网络可达
   - 确认数据库驱动依赖已正确引入（如 `mysql-connector-java`）

2. **找不到工作流配置页面**
   - 确认 `agent-web` 模块已正确打包或 Starter 已正确引入
   - 检查静态资源路径是否正确，前端文件（HTML、CSS、JS）是否在 classpath 中

3. **自动配置未生效**
   - 确认 `spring.factories` 文件中已正确注册 `InterfaceAgentAutoConfiguration`
   - 检查是否有 `@SpringBootApplication` 注解扫描到 `com.helianhealth.agent` 包

4. **MyBatis 映射错误**
   - 确认 `WorkflowAgentDataSourceConfig` 和 `WorkflowHemsDataSourceConfig` 正确配置了 `MapperScan` 和 `SqlSessionFactory`
   - 检查 XML 映射文件路径是否正确

5. **版本冲突**
   - 确保项目中 Spring Boot 版本与 `agent-spring-boot-starter` 兼容（当前为 2.3.2.RELEASE）
   - 使用 `mvn dependency:tree` 检查是否存在依赖冲突
